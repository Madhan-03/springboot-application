# Spring Boot First Application

A beginner-friendly Spring Boot application developed as part of the Full Stack Development with Java course.

## Technologies Used
- Java
- Spring Boot
- Spring Web
- Maven
- REST API

## Features
- Basic Spring Boot application setup
- REST API endpoint using `@RestController`
- GET request mapping using `@GetMapping`
- Displays a welcome message in the browser

## API Endpoint

| Method | Endpoint | Response |
|---|---|---|
| GET | `/hello` | Hello! Welcome to Spring Boot Application Created by Madhan Kumar|

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
mvnw.cmd spring-boot:run
```

4. Open the browser and visit:

```text
http://localhost:8080/hello
```

## Expected Output

```text
Hello! Welcome to Spring Boot Application Created by Madhan Kumar
```
